📖 Online Multiplayer Setup Guide

1. Go to supabase.com → create a free account → New Project.

2. In the SQL Editor, run this SQL:

CREATE TABLE IF NOT EXISTS ttt_games (
  id         TEXT PRIMARY KEY,
  board      TEXT    DEFAULT 'EEEEEEEEE',
  p1_name    TEXT    DEFAULT 'Player 1',
  p2_name    TEXT    DEFAULT '',
  turn       TEXT    DEFAULT 'X',
  status     TEXT    DEFAULT 'waiting',
  winner     TEXT    DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Allow public read/write (for this demo)
ALTER TABLE ttt_games ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_all" ON ttt_games FOR ALL USING (true) WITH CHECK (true);

3. Go to Settings → API → copy your Project URL and anon key.

4. Paste them into the Supabase Config section above → Save Config.

5. Enable Realtime on the table: Database → Replication → toggle ttt_games on.

That's it! Create a room, share the 6-digit code with your friend. ✅
